# Sales-Performance-Profitability-Analysis
📈 Sales Performance & Profitability Analysis (Python)

🧩 Project Overview

This project analyzes sales performance and profitability to help business stakeholders understand revenue trends, cost efficiency, and profit drivers across products, customers, and regions.

Using Python and data analytics best practices, the project transforms raw sales data into actionable insights that support strategic pricing, inventory planning, and revenue growth decisions.
________________________________________
🎯 Business Objectives
•	Evaluate overall sales performance

•	Measure profit and profit margins

•	Identify top and underperforming products

•	Analyze sales trends over time

•	Understand customer and regional contribution to profitability

•	Support data-driven business decisions
________________________________________
🗂️ Dataset Description

The analysis uses multiple datasets representing a realistic business scenario:

Sales Data (Fact Table)

•	Order Date

•	Product ID

•	Customer ID

•	Quantity Sold

•	Sales Revenue

•	Cost

Product Data (Dimension Table)
•	Product Name

•	Category

•	Sub-Category

•	Unit Cost

Customer Data (Dimension Table)

•	Customer Name

•	Region

•	Segment

Datasets are merged using keys such as Product ID and Customer ID to create an analysis-ready dataset.

________________________________________
🏗️ Data Modeling Approach

•	Fact & dimension modeling

•	Merged datasets follow star schema principles

•	One row represents one sales transaction
